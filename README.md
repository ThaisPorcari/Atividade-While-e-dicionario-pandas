🚀 Guia de Lógica de Programação e Análise de Dados com Python
Este projeto foi desenvolvido como um guia prático para aprender e aplicar conceitos essenciais de programação utilizando Python. O conteúdo aborda desde estruturas de controle fundamentais até a manipulação de dados em tabelas com a biblioteca Pandas.

📌 Funcionalidades e Aprendizados
1. Estruturas de Repetição (while)
O laço while é explorado através de três cenários realistas:

Contador Progressivo: O usuário define o limite e o programa realiza a contagem automaticamente.
Controle de Segurança (Login): Simulação de um sistema de login real que bloqueia o acesso após 3 tentativas incorretas.
Laço de Execução Contínua (while True): Estrutura interativa que permanece ativa até que o comando específico sair seja digitado.
Cadastro de Itens: Cadastro dinâmico de novos elementos em uma lista (ex: cadastro de carros) atualizada em tempo real.
2. Estrutura de Dados: Dicionários (dict)
Uso prático de dicionários no formato chave: valor para mapear e gerenciar dados complexos, simulando contas bancárias e seus respectivos saldos.

3. Análise de Dados com Pandas
Introdução à biblioteca Pandas, simulando o trabalho de um analista de dados:

Importação de bibliotecas (import pandas as pd).
Leitura e carregamento de arquivos estruturados (.csv).
Visualização rica de tabelas de forma organizada (display).
Geração automática de relatórios estatísticos descritivos e informativos sobre os dados (.info() e .describe()).
